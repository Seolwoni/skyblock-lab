# Marceline features

Every feature in the settings window (`/mar`), by tab. Generated from the code by `tools/gen_features.py`;
run it again after adding or describing a feature. *Full build* marks automation that only exists in the
full (non-legit) build.

## General

| Feature | What it does |
|---|---|
| Auction Price Input | Replaces the sign input with a proper textbox and undercut mode. |
| Chat Features | ChatUseful tweaks for the chat such as Ctrl + Click to copy messages. |
| Command Shortcuts | Create your own command shortcuts |
| Enchant Colors | Changes the color of enchantments in items lore. |
| Etherwarp | Etherwarp overlay and sound. |
| Etherwarp Spots | Shows where an etherwarp can land around your crosshair: green works, red doesn't (with the reason), the closest working spot gets its distance. Only while holding an AOTV with Etherwarp and with soulflow. |
| Gyro Helper | Renders a circle where your gyro will be located. |
| Human Behaviour | Makes every automatic feature move and react like a person (Assist mods style): eased curved turns, human reaction times with a drifting rhythm, aim points off-centre, a short reaction before acting on new things. Off = instant and exact. |
| Item Overlays | Display info about various items. |
| Item Rarity | Draws the rarity of item behind the slot. |
| Item Tooltip | Adds item information and controls to item tooltips |
| Loadout Keybinds | Allows you to bind loadout slots to your keyboard/mouse. |
| Party Helper | Party commands and reformatting. |
| Protect Item | Prevents dropping or selling important items via /protectitem or keybind. |
| Slot Binding | Allows you to bind slots to hotbar slots for quick item swaps. |
| Storage Overlay | Shows all storage pages in an overlay when opening storage. |
| Tac Timer | Shows a 3 seconds timer when you use the Tactical Insertion ability |
| Term AC *(full build)* | Automatically uses Salvation ability when holding right click. |
| Wardrobe Keybinds | Make it possible to bind armor slots to your keyboard. |
